# 🚀 Rekishii Lucy (Rekis) — Software Engineering Portfolio

> **Live Website**: [https://rekis-0103.github.io/portfolio/](https://rekis-0103.github.io/portfolio/)

Personal engineering portfolio website for **Rekishii Lucy (Rekis)** — Software Engineering student at President University (Batch 26) and alumnus of SMK Telekomunikasi Telesandi Bekasi (RPL).

Designed with intentional, clean, anti-AI-slop engineer aesthetics featuring real codebases, authentic tech stack SVGs, bilingual translation (ID/EN), and dual light/dark mode.

---

## ⚡ Highlights & Key Features

- **🛡️ Bespoke Engineering Design**: High-contrast, clean editorial typography (`Outfit`, `Plus Jakarta Sans`, `Fira Code`), technical grid overlays, crisp borders, and zero generic neon blobs.
- **🌐 Bilingual Switcher (ID ⇄ EN)**: Seamless real-time language switching with persistent `localStorage` preference.
- **🌓 Dual-Mode Theme (Dark / Light)**: Tailored palettes with high-contrast readability in both modes.
- **💼 Dedicated Internship Showcase**: Featuring [`compro-dan-jurnal`](https://github.com/rekis-0103/compro-dan-jurnal) (Corporate Company Profile & E-Recruitment Portal).
- **🎓 Dedicated Education Section**: Displaying official high-resolution emblems of **President University** and **SMK Telekomunikasi Telesandi Bekasi**.
- **🎨 Official Brand Vector SVGs**: Crisp, official SVG vector logos for all tech stacks and social media platforms.
- **📬 Direct Fast Channels**: Direct communication channels (Email, Discord, LinkedIn, GitHub, Instagram) with 1-click clipboard copy.

---

## 🛠️ Built With

- **HTML5**: Semantic, accessible markup with `data-i18n` bilingual attributes.
- **CSS3**: Pure Vanilla CSS, CSS Custom Properties (Tokens), responsive CSS Grid and Flexbox.
- **JavaScript (ES6+)**: Zero-dependency reactive client logic (typing animator, scroll-spy, language dictionary, theme engine).
- **Node.js**: Zero-dependency lightweight HTTP server (`server.js`) for local development.

---

## 💻 Local Development

Run locally with Node.js:

```bash
node server.js
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.
